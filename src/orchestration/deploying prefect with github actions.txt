Step 1: Connect to the "Brain" (Prefect Cloud)First, you must link your local development environment to the cloud so they can share the deployment details.Go to Prefect Cloud and create a free account.In your terminal, run:Bashprefect login
Choose "Log in with a browser" and authorize. Your terminal is now authenticated.Step 2: Build the "Instructions" (The Deployment)You need to tell Prefect what code to run. Since GitHub will be our "Chef," we need to tell Prefect to look for a specific Work Pool.Create a Work Pool in the Prefect UI:Go to Work Pools > Create.Select Process (this is the simplest type).Name it github-actions-pool.Build and Apply your deployment from your laptop:Bash# Build the manifest pointing to your pool
prefect deployment build src/orchestration/flows.py:autonomous_forex_ai \
-n github-worker-deploy \
-p github-actions-pool

# Send it to the cloud
prefect deployment apply autonomous_forex_ai-deployment.yaml
Step 3: Set the 3-Week ScheduleNow that the deployment exists in the cloud, tell it when to run. You can do this in the UI or via CLI:Bashprefect deployment set-schedule autonomous_forex_ai/github-worker-deploy --interval 1814400
Step 4: Setup the "Free Chef" (GitHub Actions)Now we need to tell GitHub to check Prefect Cloud every few minutes to see if there is any work to do. We use the prefect worker start command inside a GitHub "long-running" action.Get your API Key: Go to Prefect Cloud > Profile Settings > API Keys and generate a key.Add to GitHub Secrets: In your GitHub Repo, go to Settings > Secrets and Variables > Actions and add a secret named PREFECT_API_KEY.Create the Workflow File: Save this as .github/workflows/prefect-worker.yml:YAMLname: Prefect Worker

on:
  schedule:
    # This wakes up GitHub every day to check for scheduled work
    - cron: '0 7 * * *' 
  workflow_dispatch: # Allows manual start

jobs:
  run-worker:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.9'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Start Prefect Worker
        env:
          PREFECT_API_KEY: ${{ secrets.PREFECT_API_KEY }}
        run: |
          # The worker will run, finish the scheduled task, and then shut down
          prefect worker start --pool github-actions-pool --run-once
Step 5: Monitoring the Run in the Prefect UINow you can close your laptop. Here is how the "Magic" happens:The Trigger: Every 21 days at 7:00 AM, Prefect Cloud moves your flow from "Scheduled" to "Ready."The Execution: Your GitHub Action wakes up (via its own daily cron). It runs the prefect worker start command.The Handshake: The Worker says "I'm here!" to Prefect Cloud. Prefect Cloud says "Great, run autonomous_forex_ai now."Live Visuals: You open the Prefect Dashboard on your phone or laptop.You will see a green bar appearing in the Flow Runs tab.You can click into it to see the Logs (e.g., "Starting drift check...", "Retraining triggered").If retraining happens, you'll see the retrain_flow start as a sub-flow.Summary of the FlowComponentRoleStatusPrefect CloudThe BrainStores the schedule and logs.GitHub ActionsThe MuscleProvides the free CPU to run the code.Your LaptopThe ArchitectUsed only to write code and push updates.
